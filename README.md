# Bjärreds Brödhus

A responsive business website for a fictional local bakery in Bjärred, Sweden. The website presents the bakery, its products, a gallery, opening hours and contact information.

This project was created as part of a frontend development course and focuses on semantic HTML, CSS layout and responsive web design.

## Live website

The website is published with GitHub Pages:

[https://michaelharbst.github.io/bakery-website/](https://michaelharbst.github.io/bakery-website/)

## Features

- Header with banner, bakery information and navigation
- Home section with an introduction and calls to action
- About section presenting the bakery
- Product cards with descriptions and prices
- Responsive image gallery
- Contact information and opening hours
- Footer with contact details and a link back to the top
- Responsive layouts for desktop, tablet and mobile devices

## Project structure

```text
bakery-website/
├── index.html
├── css/
│   └── bakery.css
├── images/
├── js/
└── README.md
```

- `index.html` contains the structure and content of the website.
- `css/bakery.css` contains the colours, typography, layouts and responsive styling.
- `images/` contains the photographs used throughout the website.
- `js/` is reserved for JavaScript functionality planned for later iterations.

## Running the project locally

Clone the repository:

```bash
git clone https://github.com/michaelharbst/bakery-website.git
```

Open the project folder and launch `index.html` in a browser. Alternatively, open the project in Visual Studio Code and use the Live Server extension.

## Responsive design

The website uses CSS Grid, Flexbox and media queries to adapt its layout to different screen sizes. Product cards, gallery images, contact information and footer content change from multiple columns to a single-column layout on smaller screens.

## Deployment

The website is deployed from the `main` branch using GitHub Pages. New commits pushed to `main` are automatically published.
